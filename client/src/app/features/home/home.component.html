Security

Demonstration-grade JWT authentication with claims-based role authorization (Admin, Editor, User). Tokens are issued by the in-memory AuthController and validated on every protected request — this is not production authentication and should never be treated as such.

API Architecture

Clean ASP.NET Core layering: Controllers depend on service interfaces, services depend on repository interfaces, and repositories hold in-memory collections. No Entity Framework, no database, no migrations — state resets whenever the API restarts.

Controllers → Services → Repositories → In-Memory Collections
